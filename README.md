# 污水接管意願管理平台 (Sewage Connection Management Platform)

![Version](https://img.shields.io/badge/Version-1.5.0-blue)
![Status](https://img.shields.io/badge/Status-Production--Ready-success)
![Sync](https://img.shields.io/badge/Sync-Real--time-orange)

本平台由 **黎明工程顧問有限公司 (環工一組)** 開發，是專為污水下水道工程設計的「智慧化住戶管理與決策系統」。系統核心圍繞著「**門牌導向 (Address-Centric)**」邏輯，整合了住戶意願、現場試水與 AI 判接建議，並透過 Firebase 實現跨裝置秒級同步。

---

## 🚀 2026.05 重大版本升級 (v1.5.0)

本次更新聚焦於「資料一致性」與「管理效率」，徹底解決了大規模資料收集時的同步延遲與重複問題。

### 📍 門牌導向管理核心 (Address-Centric)
*   **地址標準化匹配**：內建地址標準化引擎，自動處理「臺/台」差異及去除多餘空格，確保住戶資料能精確掛載至預載門牌。
*   **住戶資料重複修復工具**：管理員可一鍵掃描並合併同地址的重複紀錄，自動整合意願、意見與照片。
*   **遞補邏輯**：當已註冊帳號被刪除時，系統會自動將該地址釋放回「未登錄」庫，確保街廓完整性。

### 🗺️ 智慧 GIS 與定位系統
*   **Google Maps 深度整合**：顧問端可透過地圖即時查看區域意願分佈，以顏色標註（同意/不同意/待處理）。
*   **自動經緯度解析 (Geocoding)**：匯入地址時自動抓取座標。
*   **手動座標校正模式**：支援管理員直接在地圖上點擊位置，進行點位微調。

### ⚡ 零延遲雲端同步架構
*   **全面非同步化 (Async/Await)**：重構全系統通訊層，確保每一筆意願與照片在重新整理網頁前，已 100% 寫入 Firebase 雲端。
*   **可靠的寫入鎖定**：杜絕了因網路波動導致的「看得到統計、看不到資料」問題。

## 👤 角色功能總覽 (Role-Based Features)

### 🏠 住戶端 (Resident)
*   **快速登入**：支援選取案名與地址，防止輸入錯誤。
*   **多媒體回饋**：除意願選擇外，支援現場環境照片上傳。
*   **即時確認**：提交後立即生效，無須等待後端審核。

### 🛠️ 廠商端 (Contractor)
*   **批次試水回報**：針對整條水系進行試水結果快速錄入。
*   **街廓清單管理**：自動過濾出其負責的街廓範圍。

### 📊 顧問公司 (Consultant)
*   **大數據儀表板**：自動產出意願加總統計與圓餅圖。
*   **AI 智慧判接建議**：系統會根據「意願 > 50%」及「試水通過」自動推薦前巷或後巷接管方案。
*   **GIS 意願分布圖**：直觀掌握工程推動難點。

### 🛡️ 管理員 (Administrator)
*   **帳號分級審核**：廠商與顧問需經管理員核准後方可使用。
*   **人員完全控制**：可直接查看、修改（包含密碼重置）與刪除所有人員帳號。
*   **資料清理工具**：包含清除測試資料、清除預載座標、資料合併等進階功能。

## 🔒 安全性規範

為提升系統人員帳號安全性，管理人員（廠商、顧問）密碼需符合：
*   **包含至少 1 位英文字母** (不分大小寫)。
*   **總長度至少為 6 碼**。
*   管理員具備最高權限，可直接在後台監控並協助重置密碼。

## 🛠️ 技術棧 (Technology Stack)

*   **前端**: Vanilla JS / CSS3 (Glassmorphism 風格)
*   **資料庫**: Firebase Realtime Database
*   **地圖引擎**: Leaflet.js / Google Maps API (Tiles)
*   **圖表引擎**: Chart.js
*   **Excel 處理**: SheetJS (XLSX.js)
